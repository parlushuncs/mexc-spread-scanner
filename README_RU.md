# MEXC Spread Scanner

Веб-сканер публичных USDT perpetual futures MEXC. Обновляет данные каждые 10 секунд, фильтрует по спреду и считает глубину стакана.

## Что делает
- Получает список активных USDT perpetual futures через публичные Futures REST API.
- Рассчитывает spread = (ask1 - bid1) / ((ask1 + bid1) / 2) * 100.
- По умолчанию показывает спред от 5%, можно менять порог в браузере.
- Сортировка по спреду, обороту 24ч или open interest.
- Для 30 контрактов с самым широким спредом получает стакан и считает номинал bid/ask в диапазонах ±1%, ±3%, ±5%, ±10% от mid.
- Уведомления браузера о появлении новых контрактов выше выбранного порога.
- Только публичные данные: API-ключи MEXC не нужны, ордера не размещаются.

## Локальный запуск
Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

## Онлайн-развёртывание на Render
1. Создайте GitHub-репозиторий и загрузите в него содержимое этого проекта.
2. В Render выберите New → Web Service → подключите репозиторий.
3. Render распознает `render.yaml` или выберите Docker как Runtime.
4. После сборки Render выдаст публичный HTTPS URL. Открывайте его с любого компьютера.
5. Для постоянной работы выберите платный постоянно работающий тариф. Бесплатные тарифы хостинга могут засыпать и задерживать обновления.

## Переменные окружения
- `REFRESH_SECONDS=10` — интервал сканирования.
- `DEPTH_SYMBOL_LIMIT=30` — для скольких самых широких спредов запрашивать стакан за цикл.
- `MIN_SPREAD_DEFAULT=5` — начальный порог интерфейса.

## Важные ограничения
- MEXC может менять API, лимиты запросов и доступность контрактов.
- Глубина запрашивается для топ-30 по спреду, а не для каждого контракта: это ограничивает нагрузку на публичный API. Контракты вне этой группы отображаются с `н/д` в колонках глубины.
- В стакане MEXC объём уровня указан в контрактах. Номинал переводится в USDT как price × contracts × contractSize из справочника контрактов. Если размер контракта отсутствует, используется 1; для такого контракта оценка глубины может быть неточной.
- Спред — это мгновенный снимок лучших bid/ask, а не гарантия исполнения по этим ценам.
- Браузерные уведомления работают, когда страница открыта и браузер разрешил уведомления.
- Для надёжной круглосуточной работы нужен постоянно работающий сервер. Сервис не хранит API-ключи и не торгует.
